그 밖의 개선

  • Data Visualization 표의 행·열 삭제 (헤더 셀에 마우스를 올리면 × 표시)
  • 섹션 삭제 버튼을 눈에 띄게 강조
  • 헤더 버튼 정리, 링크 스타일 통일
  • Change History의 제목과 필터를 한 줄로 배치
  • Formulation 배합 선택 → Link Formulations: 하는 일(노트에 배합 연결, 2개 이상이면 비교 표시)에 맞게 이름 변경. 기본 범위는 이 노트의 연결 프로젝트 전체(Primary만 아님), All projects로 넓혀 검색 가능. 표에 배합 이름·Project # 표시 (운영 Formulator 데이터에 프로젝트 번호가 있다는 전제)
  • Sticky note에 작성자·시각 표시. 볼 수 있는 사람 = 그 섹션을 볼 수 있는 사람(Share & Access 범위 그대로, 메모별 별도 공유 없음) — 메모는 섹션 밖으로 나가지 않음
  • 노트 상태 표기를 결재 상태 하나로 통일: 리스트·노트 헤더·Note List 모두 In Progress → In Approval → Approved (기존 리스트의 Success / Failed / On Hold, Done / In Review / Draft 표기 폐기)
  • Formulation 섹션은 노트당 하나: 지운 뒤 Add Module로 다시 고르면 원래 섹션이 복원됨(빈 섹션이 새로 생기지 않음)
