3. Production build notes Server · database

  • Note basic data: title, creation date (time of the first save, recorded by the server), Primary Business and Segment (production DEXIF Business and Segment codes), Site (production lib_site code). Other Business(es) in a note-to-business link table (several)
  • Related Items: a note-to-item link table (type Project, Material, Lab Note or URL; code or URL). Project search reuses the production TechLib project search API
  • Approval: the common production approval module (approval line, submit, withdraw, decision) used as is, per note. No server logic for per-section approval is needed (dropped from the Doc 1 plan)
  • Required checks: the screen uses the common production checks (data-required, data-required-appronly); the server checks the same fields again on save and on submission
  • Attachments: the common production attachment parts (File button, chips, drag and drop) plus ELN version history (same name → new version)
  • Audit Trail: the server records entries on save, approval and sharing; the viewing screen is a new admin menu page
