Other improvements

  • Rows and columns can be deleted in Data Visualization tables (hover over a header cell to show ×)
  • The section delete button now stands out
  • Header buttons tidied up, link styles unified
  • The Change History title and filters placed on one line
  • Formulation selection → Link Formulations: renamed to match what it does (links formulations to the note and shows a comparison when there are two or more). The default scope is all projects linked to this note (not only the Primary), and the search can be widened to All projects. The table shows the formulation name and Project # (assuming production Formulator data carries the project number)
  • Sticky notes show the author and time. Who can see them = whoever can see that section (the Share & Access scope as is, no separate sharing per sticky note). Sticky notes never leave their section
  • Note status unified into the single approval status: the list, the note header and Note List all show In Progress → In Approval → Approved (the old list labels Success / Failed / On Hold and Done / In Review / Draft are dropped)
  • One Formulation section per note: after it is deleted, choosing it again in Add Module restores the original section (no new empty section is created)
