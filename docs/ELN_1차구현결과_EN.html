Other improvements

  • Rows and columns can be deleted in Data Visualization tables (hover over a header cell to show ×)
  • The section delete button now stands out
  • Header buttons tidied up, link styles unified
  • The Change History title and filters placed on one line
  • Formulation selection → Link Formulations: renamed to match what it does (links formulations to the note and shows a comparison when there are two or more). The default scope is all projects linked to this note (Project items in Related Items), and the search can be widened to All projects. The table shows the formulation name and Project # (assuming production Formulator data carries the project number)
  • Sticky notes show the author and time. Who can see them = whoever can see that section (the Share & Access scope as is, no separate sharing per sticky note). Sticky notes never leave their section
  • Note status unified into the single approval status: the list and the note header both show In Progress → In Approval → Approved (the old list labels Success / Failed / On Hold and Done / In Review / Draft are dropped)
  • Dates shown in the MAPIS standard MM-DD-YYYY (production format MM-dd-yyyy). Experiment Date uses the standard date picker (before, the format changed with the PC language)
  • The summary panel on the right of the list now uses the MAPIS standard summary layout (same as the Tech Library and Composition lists): title link, label/value rows, section headings (Related Projects · Modules · Tags), status as colored text, wider panel
  • One Formulation section per note: after it is deleted, choosing it again in Add Module restores the original section (no new empty section is created)
  • The Related Items add row uses the MAPIS standard input: Material · Project · Note share the same input with the common autocomplete, URL is a plain input
  • The Share & Access table follows the MAPIS standard: Function badges (Owner filled · Co-editor blue outline · Viewer grey outline), Edit · Remove icons appear only when the row is hovered, and Remove revokes access only after a confirmation (Confirm / Cancel)
  • List: the selected row no longer drops down on hover (2px shift removed); the New Notebook button is a plain button
