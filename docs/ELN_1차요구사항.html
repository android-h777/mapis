Lab Note(ELN) 프로토타입 구현 목록

2026-10-14 · 대상 화면: 연구노트 리스트 / 노트 상세 팝업
각 항목에 마우스를 올리면 상세 설명과 화면 변화가 표시됩니다. (모바일은 탭)

구현 항목

No기능내용화면
1단계 · 기록 신뢰성
1헤더 필드 추가Basic Data에 실험일자, NPI 번호(여러 개), Platform Tech/Pre-NPC(NPC 번호가 없는 과제용), 종이 노트 참조(노트북·페이지) 입력란 추가팝업
2Co-Signer 서명기존 Approval 카드를 교체. 작성자가 서명자를 직접 지정하고, 섹션별 또는 노트 전체를 제출. 서명자는 승인·반려와 코멘트 입력팝업
3제출 후 잠금 · Errata제출된 섹션은 수정 불가(잠금 표시). 고칠 내용은 Errata(정정 기록)로 덧붙이고, 새 섹션 추가는 허용팝업
4Audit Trail노트의 모든 변경을 시간순으로 기록·조회. 누가, 언제, 어떤 항목을, 어떤 값에서 어떤 값으로 바꿨는지 표시팝업
2단계 · 협업 · 검색
5공동 편집자노트에 공동 편집자 지정. 헤더에 참여자, 섹션마다 마지막 편집자 표시. 다른 사람이 편집 중인 섹션은 잠금팝업
6공유노트 전체 또는 일부 섹션을 다른 사용자에게 공유. 권한(보기·코멘트·편집) 지정, 공유 사유 입력과 컴플라이언스 확인팝업
7노트 복제기존 노트를 복사해서 새 노트 시작. 복사할 섹션과 데이터 포함 여부 선택리스트·팝업
8노트 상호참조본문에서 @ELN번호로 다른 노트를 링크. 내 노트, 다른 연구원 노트 모두 가능팝업
9검색 확장기존 검색(키워드·태그·상태·노트북)에 저자, 프로젝트, NPI 번호, 첨부파일 본문 검색 추가
구조식 검색검토 중 화학 검색 엔진 필요		리스트
10권한 없는 노트 검색열람 권한이 없는 노트도 검색 결과에 표시. 번호·제목·저자·날짜만 보이고, 클릭하면 열람 요청리스트
3단계 · 콘텐츠
11첨부 미리보기파일서버에 저장된 Word·Excel·PPT·PDF·이미지·동영상을 노트 안에서 바로 미리보기. 수정본을 다시 올리면 새 버전으로 쌓임팝업
12SharePoint 작업 문서
검토 중		SharePoint 문서 링크를 연결해 노트 안에서 보고, 웹·데스크톱 Office로 편집. 작업용이므로 법적 기록에는 포함하지 않음팝업
13ChemStudio 연동자체 구현한 ChemStudio로 구조식·반응식을 그리고, 분자량 등을 노트에 표시팝업
14PDF 내보내기노트를 PDF 파일로 저장팝업
15번역노트 텍스트를 다른 언어로 번역해서 보기팝업

기존 기능 유지: 템플릿, 태그, 관련 항목 링크, Excel 붙여넣기 → 표·차트, 구조화된 데이터 저장
